ProjeX Chat Plugin

Vanilla JavaScript Example - Drop-in Chat Widget

1. Basic Usage (Bottom-Right Widget)

The simplest way to add the chat widget to your page:

<script src="../src/projex-chat.js"></script>
<projex-chat api-url="https://your-api.vercel.app"></projex-chat>

Result: A floating chat button appears in the bottom-right corner. Click it to open the chat!

2. Customization Options

Customize the appearance and behavior:

<projex-chat
  api-url="https://your-api.vercel.app"
  theme="dark"
  title="Custom Assistant"
  placeholder="Ask me anything..."
  quick-questions='["Question 1", "Question 2"]'
  open
></projex-chat>

3. Programmatic Control

Control the chat widget with JavaScript:

const chat = document.querySelector('projex-chat');

// Open/close
chat.open();
chat.close();
chat.toggle();

// Send message
chat.sendMessage("Tell me about ProjeX");

// Clear history
chat.clearHistory();

// Get history
const history = chat.getHistory();

4. Event Listeners

Listen to chat events:

chat.addEventListener('message-sent', (e) => {
  console.log('User sent:', e.detail.message);
});

chat.addEventListener('response-received', (e) => {
  console.log('AI responded:', e.detail.response);
});

chat.addEventListener('error', (e) => {
  console.error('Error:', e.detail.error);
});
