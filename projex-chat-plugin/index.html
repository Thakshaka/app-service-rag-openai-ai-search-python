ProjeX Chat Plugin

Embeddable AI Chat Widget v1.0.0

🚀 Quick Start

Add this to your HTML:

<!-- Add the chat widget -->
<projex-chat 
    api-url="https://your-backend.azurewebsites.net"
    title="ProjeX Assistant"
    show-citations="true">
</projex-chat>

<!-- Load the plugin -->
<script src="https://your-cdn-url/projex-chat.js"></script>

📦 Available Files

  • projex-chat.js - Latest version (recommended)
  • projex-chat.min.js - Minified version

⚙️ Configuration

Available attributes:

<projex-chat
    api-url="string"
